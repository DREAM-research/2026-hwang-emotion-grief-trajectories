# Early Neural Responses to Negative Emotional Processing and Longitudinal Grief Trajectories in Later Life

Hwang G et al. *Psychotherapy and Psychosomatics*. In press.

## Scripts

- `scripts/task/`: task activation
- `scripts/gppi/`: task-dependent connectivity
- `scripts/rest_proc/`: resting-state connectivity
- `scripts/clinical/`: cluster correction

Python 3.9. Install with `pip install -r requirements.txt`. Use `--help` for script arguments.

No study data are included.
